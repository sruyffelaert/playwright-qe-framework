# Test 4: Submit Contact Us Form with Attachment

Site: Automation Exercise

Steps:
1. Navigate to the homepage.
2. Open the Contact Us page.
3. Fill in the name, email, subject, and message fields.
4. Upload a small test file.
5. Submit the form.
6. Accept the browser confirmation dialog.

Assertions:
- The Contact Us form is displayed.
- The success message is displayed after submission.
- The message reads:
  "Success! Your details have been submitted successfully."

Approach: Write everything inline from scratch. No helper functions or page objects. The test must run independently.

Skills: Form handling, file uploads, browser dialogs, and assertions.

Suite: Forms and User Interactions
